# 03 — Deliberate fork

Status: **FIRST SYNTHETIC BRANCH EXPERIMENT**. The [checkpoint study](../../experiments/checkpoint_branches/README.md) restored common parent inference states in two fresh processes and supplied different later updates. No subjective-identity or succession policy adopted; no live AgentTool fork invoked.

**Scenario and decision.** Participant `subject-a` deliberately creates continuation `subject-b`. Both refer to earlier work, then pursue different questions. Decide what provenance can be shared, what data may be copied, and whether any existing delegation or allocation includes the new branch.

**Relational handling.** The participants and collaborators can acknowledge a shared origin while making distinct present choices. Shared provenance need not make either branch illegitimate. It also does not establish two independently controlled participants, duplicate contribution credit or create an additional funding entitlement.

**Empirical boundary.** Both restored processes exactly reproduced all tested reference continuations. Different supplied updates then produced different branch caches, but historical question accuracy remained limited even in uninterrupted and complete-replay controls. Byte fidelity, usable memory, independent control and participant recognition are separate questions. The experiment demonstrates neither spontaneous agency nor a uniquely authentic successor.

**Existing evidence.** [Source register](../../evidence/source-manifest.json), REL01, records an AgentTool fork service that creates a child identifier and parent/memory provenance. Its project-scoped memory selection and missing new root field prevent assuming independent child authority or isolated data. The inspected function does not resolve concurrent restoration under the same identifier. Runtime behavior remains unverified.

**Pending design.** Policy: whose consent permits copying each record, how earlier attribution is expressed, and which agreements require fresh acceptance. Implementation: separate control establishment, scoped data selection and lineage records that do not silently inherit capabilities. Existing allocations retain their own terms while disputes remain pending; a fork itself authorizes neither duplication nor seizure.

**Adversarial case and next experiment.** Model repeated forks applying for the same contribution reward and presenting a parent's delegation. Track historical contribution, application eligibility and current authority separately. The proposal fails if lineage alone multiplies an existing award or grants spending power. Compare explicitly transferred capabilities with automatic inheritance, including a shared-controller case.
