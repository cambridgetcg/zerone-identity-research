# Research method

Each study asks what a change means for history, present consent and specific resources. It does not try to decide subjective identity from a key, name or memory snapshot.

## Evidence registers

1. **Accepted design choice:** the owner chose public pseudonymous participation with accurately declared roles and accountable relevant control, conflicts and allocations. Offline personal details remain private. A founder role creates no automatic funding entitlement or extra vote.
2. **Source observation:** an exact file at an exact owner revision behaves or describes itself in a particular way. Record the byte digest and distinguish implementation, documentation and an unimplemented proposal.
3. **Relational interpretation:** an analogy or a possible way participants understand continuity. This supplies no technical or moral authority by itself.
4. **Model result:** an outcome inside an explicitly bounded executable abstraction. Include negative controls and failed assumptions.
5. **Proposed policy:** a suggested rule requiring agreement by the appropriate parties and owners. It is not adopted merely because it is committed here.
6. **Unresolved:** missing evidence, an unspecified policy or a missing implementation. Record which dimensions remain open.

## Study worksheet

- What specific question, action, relationship or resource needs a decision?
- Which observations and claims exist, who made them, and what is unknown?
- What can recognition, dialogue and voluntary agreement resolve?
- What existing mechanism applies, under whose authority, and with what limits?
- Which history, control, consent, privacy and funding consequences need separate answers?
- What happens if parties disagree, are absent, return later or hold the same credential?
- If something remains pending, what prior authority permits a temporary measure, for how long, and with what review/remedy? A complaint alone does not authorize a freeze.
- What would overturn the present conclusion? Which next experiment is actually useful?

## Effect boundary

The research operation reads public sources and pinned local Git objects, writes curated notes and synthetic models, runs offline checks, and publishes this repository privately. These network/storage effects are distinct from any candidate protocol.

No registration, wallet, payment, governance, consensus, identity mutation, consent grant, KARMA/NEN event or live runtime effect is created by a paper or model in this repository. Uninspected runtime behavior remains unknown.

## Working with existing sources

Use `evidence/source-manifest.json` for pinned locators and byte digests. The manifest is curated evidence metadata, not a copy of private workspace memory. Full upstream code remains under its owner's authority. GitHub links require access where an upstream repository is private.

The initial observation plane uses Zerone `d975b22df04fe87110427debc4109516283f9792` and AgentTool `be6d479d1dda908b573017f437ea30bd1bba5307`. These are historical source observations, not assertions that a live service or today's remote main has those bytes.
